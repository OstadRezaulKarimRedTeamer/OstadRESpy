## [+] OstadBitDiff - Top 1% Universal Binary Diffing Engine

**OstadBitDiff** হলো একটি বিশ্বমানের বাইনারি ডিফারেন্সিয়াল ফরেনসিক্স ইঞ্জিন, যা দুটি ফাইলের (Original vs Modified/Backdoored) মধ্যে প্রতিটি বাইট, সেকশন এবং মেমোরি ক্লাস্টার ব্যবচ্ছেদ করে:
* **ট্রোজান ও ব্যাকডোর ইনজেকশন ডিটেকশন:** একটি অরিজিনাল সফটওয়্যারে হ্যাকাররা নতুন কী কী কোড, বিপজ্জনক API বা C2 লিংক ঢুকিয়েছে তা নিমেষেই আলাদা করে দেয়।
* **১-ডে সিকিউরিটি প্যাচ ডিফারেন্সিয়াল (Patch Diffing):** পুরোনো ও নতুন ভার্সনের পার্থক্য বের করে সিকিউরিটি ফিক্স বিশ্লেষণ করে।
* **কনটেইনার ও মেম্বার ডেল্টা:** APK বা ZIP-এর ভেতরে কোন কোন ফাইল যোগ, ডিলিট বা পরিবর্তন করা হয়েছে তা বের করে।

## 🚀 যেকোনো ডিভাইসে অতি সহজে চালানোর নিয়ম (Universal 1-Click Guides)

### 📱 ১. অ্যান্ড্রয়েড মোবাইল ফোনে সরাসরি যাচাই করার নিয়ম (Termux)
1. ফোনে **Termux** অ্যাপটি ওপেন করে স্টোরেজ পারমিশন দিন:
   ```bash
   termux-setup-storage
   ```
2. ডাউনলোড করা যেকোনো APK বা ফাইল টেস্ট করতে লিখুন:
   ```bash
   bash run_on_android.sh /sdcard/Download/app.apk
   ```
   *বা দুটি APK ডিফ করতে:*
   ```bash
   bash run_bitdiff_android.sh /sdcard/Download/clean.apk /sdcard/Download/modded.apk
   ```

### 💻 ২. উইন্ডোজ পিসিতে চালানোর নিয়ম (Windows 1-Click Drag & Drop)
* **OstadRESpy (সিঙ্গেল ফাইল স্ক্যান):** যেকোনো ফাইল মাউস দিয়ে টেনে এনে **`run_ostadrespy.bat`**-এর ওপর ছেড়ে দিন!
* **OstadBitDiff (দুটি ফাইল তুলনা):** দুটি ফাইল মাউস দিয়ে টেনে এনে **`run_bitdiff.bat`**-এর ওপর ছেড়ে দিন!

### 🐧 ৩. লিনাক্সে চালানোর নিয়ম (Linux / Kali / Ubuntu)
```bash
chmod +x run_ostadrespy.sh run_bitdiff.sh
./run_ostadrespy.sh target_file
./run_bitdiff.sh file1.exe file2.exe
```

### 🍎 ৪. ম্যাক কম্পিউটারে চালানোর নিয়ম (macOS)
```bash
chmod +x run_ostadrespy.sh run_bitdiff.sh
./run_ostadrespy.sh /path/to/any_file
./run_bitdiff.sh original.dmg patched.dmg
```
